# Gesture & Voice Controlled Virtual Mouse

An intelligent Human-Computer Interaction (HCI) system that allows users to control a computer using **hand gestures**, **voice commands**, and a **web-based interface**, eliminating the need for traditional input devices like a mouse and keyboard.

---

## 🚀 Features Overview

The system is divided into three major modules:

- ✋ Gesture Control Module  
- 🎙️ Voice Assistant Module  
- 🌐 Web Interface Module  

---

## ✋ Gesture-Based Controls

### 🖱️ Cursor & Navigation
- Move Cursor using fingertip tracking  
- Neutral Gesture to pause/stop control  

### 🖱️ Click Actions
- Left Click  
- Right Click  
- Double Click  

### 🖱️ Advanced Operations
- Drag and Drop  
- Multiple Item Selection  

### 🔄 Scrolling (FUTURE SCOPE)
- Vertical Scrolling  
- Horizontal Scrolling   

---

## 🎙️ Voice Assistant (Nova)

### ⚙️ System Control
- `Nova Launch Gesture Recognition` → Start gesture system  
- `Nova Stop Gesture Recognition` → Stop gesture system  

### 🌐 Web Commands
- `Nova search <query>` → Search on Google  
- `Nova find a location` → Open location in Maps  

### 📁 File Navigation
- `Nova list files` → List files in directory  
- `Nova open <number>` → Open file/folder  
- `Nova back` → Go to parent directory  

### ⏰ Utility
- `Nova time` → Get current time  
- `Nova date` → Get current date  

### 📋 Productivity
- `Nova copy` → Copy selected text  
- `Nova paste` → Paste copied text  

### 💤 Assistant Controls
- `Nova bye` → Sleep mode  
- `Nova wake up` → Resume  
- `Nova exit` → Exit assistant

## 🧠 Tech Stack

- Computer Vision: MediaPipe, OpenCV  
- Voice Processing - Natural Language Processing: Speech Recognition, PyAudio  
- Backend: Python, Supabase(PostgreSQL)  

---

## ⚙️ Working

1. Webcam captures hand movements  
2. MediaPipe detects hand landmarks  
3. Gestures are classified and mapped to actions  
4. Voice assistant processes commands  
5. Web interface manages and monitors the system
